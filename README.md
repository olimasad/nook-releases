# Nebula Nook — desktop releases

Public Windows installers for [Nebula Nook](https://nook.oliverms.com).

Source code lives in a private repo; **this repo only holds release binaries** so downloads and auto-updates work for everyone.

- Site download: https://nook.oliverms.com/api/desktop/download
- Updater feed: https://nook.oliverms.com/api/desktop/update

Artifacts are uploaded by CI when a `v*` tag is pushed on the source repo.
